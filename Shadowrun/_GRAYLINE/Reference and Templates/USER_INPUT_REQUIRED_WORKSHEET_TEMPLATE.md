## 5. Allowed Answers

Use only the answers that make sense for the decision.

- APPROVE: Accept this content, placement, or boundary.
- CORRECT: The idea is usable, but something needs to be changed. Add the correction in Notes / Correction.
- REJECT: Do not use this content, placement, or boundary.
- DEFER: Leave this unresolved for now. Add the reason if useful.
- GM-ONLY: Keep this hidden from players and internal to the GM/campaign-management side.
- PLAYER-FACING SAFE: This can appear in player-facing derived output.
- MOVE: The content belongs somewhere else. Add the target location in Notes / Correction.
- CONSOLIDATE LATER: Keep for now, but consider merging or simplifying in a later cleanup task.

## 6. Machine-Readable Handling

Machine-readable output should be generated by Codex from the completed human-facing decision cards.

If a future UI needs structured data, Codex should derive it from:

- Decision ID

- Notes / Correction
- Recommended Answer
- Allowed Answers

Codex must not treat recommended answers as user answers.

If required answers are missing or invalid, Codex must stop and identify the missing or invalid decision IDs.
