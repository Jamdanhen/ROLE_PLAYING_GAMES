## Editing Intent

Use this map as the active isolated baseline. Future changes should modify or derive from this folder first, not from the other Grayline draft SVG files in the parent project folder.

## Map Design Rules

- Do not create perfectly straight main roads.
- Main roads should use natural, subtle curves that feel engineered but not ruler-straight.
- Curves should be gentle and readable, not squiggly.
- Rail lines may run straighter than roads, but should still follow district contours when appropriate.
