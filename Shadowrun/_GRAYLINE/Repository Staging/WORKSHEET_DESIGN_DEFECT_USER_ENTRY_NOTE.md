# WORKSHEET_DESIGN_DEFECT_USER_ENTRY_NOTE.md

## Status

DESIGN DEFECT CONFIRMED

## Summary

The prior Session 000 worksheet failure was a worksheet design defect, not user error.

## Defect

The worksheet presented multiple apparent answer locations:

- A Quick Answer Table.
- Repeated detailed question sections.
- A machine-readable response block.

The user reasonably entered answers in the detailed question sections because that is where the full plain-English questions appeared.

The parser treated only the Quick Answer Table or machine-readable response block as valid answer locations.

## Correction

Future worksheets must use one self-contained decision-card format per decision.

The answer field must appear directly under the full question.

The user must not be required to scroll between summary tables and detailed question text.

The worksheet must not create duplicate or competing answer locations.

The user must not be asked to manually complete a machine-readable block.

## New Standard

Each decision should appear as:

Decision ID:
[ID]

Question:
[Full plain-English question]

Your Answer:
[blank]

Notes / Correction:
[blank]

Recommended Answer:
[recommendation]

Allowed Answers:
[allowed answer list]

Why This Matters:
[brief context]

## Machine-Readable Handling

Machine-readable output should be generated by Codex from the completed human-facing answers.
