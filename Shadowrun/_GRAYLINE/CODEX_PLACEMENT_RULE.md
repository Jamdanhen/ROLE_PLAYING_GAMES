# Codex Placement Rule

For Shadowrun Codex / Grayline generation work, keep generated files inside this existing `_GRAYLINE` structure.

Do not create new C-drive root folders for Shadowrun Codex outputs unless the user explicitly asks for that.

Default destinations:

- Maps, map images, SVG maps, area maps, district maps, location diagrams, and visual map exports:
  `C:\ROLE_PLAYING GAMES\Shadowrun\_GRAYLINE\Maps`
- Player-facing handouts and dossier-style outputs:
  `C:\ROLE_PLAYING GAMES\Shadowrun\_GRAYLINE\Handouts and Dossiers`
- Campaign notes, setting notes, and authored Grayline text:
  use the closest existing folder under `C:\ROLE_PLAYING GAMES\Shadowrun\_GRAYLINE`

Before creating a new folder, scan the existing `_GRAYLINE` folders and reuse the closest appropriate folder.
